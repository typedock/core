# Social

Adds two components:

- `social_share`: share links for the current page or post.
- `social_follow`: links to social profiles configured through component parameters.

This plugin does not add a dedicated settings screen. After enabling it, insert the components from the editor slash menu with Component Block, or place them in theme slots from Appearance -> Slots.

## Social Share

Common parameters:

- `networks`: comma-separated list such as `x,facebook,linkedin,email,copy`.
- `label`: optional visible label.

Allowed networks include `x`, `facebook`, `linkedin`, `bluesky`, `mastodon`, `hatena`, `line`, `email`, and `copy`.

## Social Follow

Add profile links through the component parameter editor. Theme CSS controls the final presentation.
