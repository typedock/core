# Image Optimizer

Tunes TypeDock's built-in image processing defaults.

This plugin does not generate a separate admin screen. When enabled, it configures JPEG/WebP quality and maximum image dimensions during media upload.

## What it does

- Sets JPEG quality.
- Sets WebP quality.
- Sets the maximum image edge used by the core media pipeline.

## What it does not do

- WebP variant generation is handled by Core MediaService for JPEG and PNG uploads.
- Thumbnail sizes are generated by Core only when the uploaded image is larger than the requested size.

If an uploaded image is already small, some thumbnail sizes may not be created. That is expected behavior.
